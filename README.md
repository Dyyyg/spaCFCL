# spaCFCL

**spaCFCL: Cross-foundation collaborative learning for spatial domain identification in multi-omics data**

[![Python](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![PyTorch](https://img.shields.io/badge/PyTorch-1.13.0-red.svg)](https://pytorch.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE.md)

spaCFCL integrates spatial transcriptomics with a second modality (protein / ADT or chromatin accessibility / ATAC) by coupling two independently pre-trained single-cell foundation models — **Geneformer** and **scGPT** — with graph-based multi-omics fusion and InfoNCE contrastive alignment.

## Introduction

Spatial multi-omics technologies enable the joint profiling of multiple molecular modalities while preserving tissue spatial context, thereby providing valuable information for characterizing tissue architecture. However, existing methods do not fully exploit the complementary information captured by representations from different foundation models. Moreover, differences in the feature distributions and semantic structures of latent representations from heterogeneous foundation models pose challenges for cross-model information integration. To address these challenges, we propose spaCFCL (Cross-Foundation Model Collaborative Learning for Spatial Multi-omics Domain Identification), a cross-foundation-model collaborative learning framework for spatial multi-omics domain identification. The framework jointly leverages the pretrained representations of Geneformer and scGPT and employs a Cross-Foundation Semantic Alignment (CFSA) mechanism to promote semantic consistency between representations generated by the two models at corresponding spatial locations. Furthermore, it adopts a Hierarchical Cross-Modal Fusion (HCMF) strategy to progressively integrate foundation-model representations, spatial structural information, and complementary omics features, thereby learning a joint latent representation for spatial domain identification. We evaluated spaCFCL against several representative baseline methods on four publicly available spatial multi-omics datasets encompassing different combinations of omics modalities. The experimental results demonstrate that spaCFCL outperforms the baseline methods in spatial domain identification on datasets with reference spatial-domain annotations. On the dataset lacking complete reference annotations, spaCFCL also achieves better performance than the baseline methods in terms of spatial structure-related metrics.

## Installation

### Requirements

- `Python 3.8+`  and all versions are pinned in [`requirements.txt`](requirements.txt)
- **R** with the `mclust` package, accessed through `rpy2` (only needed for the default `mclust` clustering; `leiden` / `louvain` are supported as fallbacks and need no R)
- A CUDA-capable GPU is recommended. The scripts currently assign `torch.device('cuda')` unconditionally — change that line to `torch.device('cpu')` if you have no GPU.

### Clone and set up

```bash
git clone https://github.com/Dyyyg/spaCFCL.git
cd spaCFCL
```

Create the environment and install the pinned dependencies:

```bash
conda create -n spaCFCL Python 3.8
conda activate spaCFCL
pip install -r requirements.txt
```

Two machine-specific settings appear in every script and **must** be edited before the first run:

```python
os.environ['R_HOME'] = r'Path to your R installation'
file_fold = 'path to your dataset folder'
```

---

### Run

With the environment activated and the two settings above filled in, run the entry-point script from the repository root:

```bash
python scripts/main.py
```

## Evaluation

### Datasets with spot-level reference annotations

For datasets that provide spot-level reference annotations, the agreement between the predicted spatial domains and the reference labels is measured with the **Adjusted Rand Index (ARI)**, **Normalized Mutual Information (NMI)**, **Adjusted Mutual Information (AMI)**, **V-measure**, and **Homogeneity**. All of these are "higher-is-better" metrics: a larger value indicates closer agreement between the clustering and the reference annotation.

| Metric      | Direction | Notes                                       |
| ----------- | --------- | ------------------------------------------- |
| ARI         | higher ↑  | adjusted Rand index                         |
| NMI         | higher ↑  | normalized mutual information               |
| AMI         | higher ↑  | adjusted mutual information                 |
| V-measure   | higher ↑  | harmonic mean of homogeneity & completeness |
| Homogeneity | higher ↑  | each cluster contains only one class        |



### Datasets without complete spot-level annotations

For datasets that lack complete spot-level reference labels, the predicted spatial domains are evaluated quantitatively from the perspectives of **spatial autocorrelation**, **spatial continuity**, and **local neighbourhood consistency**, using **Moran's I**, **Geary's C**, **Spatial chaos score (CHAOS)**, and **Percentage of abnormal spots (PAS)** .

| Metric    | Direction | Notes                                                     |
| --------- | --------- | --------------------------------------------------------- |
| Moran's I | higher ↑  | stronger spatial autocorrelation                          |
| Geary's C | lower ↓   | stronger local spatial similarity                         |
| CHAOS     | lower ↓   | more continuous spatial structure                         |
| PAS       | lower ↓   | smaller fraction of abnormal (spatially incoherent) spots |

In addition, the predicted spatial domains are validated biologically by examining the expression patterns of known marker genes, which further assesses the biological plausibility of the identified spatial regions.

## Acknowledgement

This implementation builds on the ideas and code of the following open-source projects and resources:

- [spaLLM](https://github.com/liiilongyi/spaLLM) — a related spatial multi-omics integration framework that inspired parts of the fusion design.

- [scGPT](https://github.com/bowang-lab/scGPT) — generative pre-trained single-cell model, the second reference foundation model.
- [Ensembl BioMart](https://www.ensembl.org/info/data/biomart/index.html) — source of gene annotations and gene-ID mappings used in the preprocessing pipeline.
- [scanpy](https://scanpy.scverse.org/en/stable/) — single-cell analysis toolkit for preprocessing, clustering, and visualization.
